2. Amazon 部门红黑榜动态矩阵

切换查看推荐投递与高危避坑团队：

AWS 云计算核心 (EC2 / S3 / DynamoDB / Aurora)
推荐理由：全球云计算霸主底座！技术硬实力极强，履约与分布式架构含金量极高，全球认可度无敌。
卖家服务与跨境电商核心 (Seller Partner Services)

高 Unreg Rate / 强制 PIP 配额高的重灾组
避坑理由：高危避坑组！ Amazon 拥有约 6%-10% 的 Unreg 淘汰指标，某些高压组 On-call 频次极高且容易陷入 PIP 险境。

工作作息与 16 条 LP 准则

工作作息 (WLB 视团队而定)

普遍下班时间在 18:30 - 19:30。但 On-call 轮值期间需保障 P0 故障 15 分钟内响应。

16 条 Leadership Principles (LP)

Customer Obsession, Ownership, Bias for Action 等准则贯彻日常考核与代码审查。

Focus & PIP 绩效淘汰

每年末位流转考核，强调 Operational Excellence（运维卓越与指标监控）。

Amazon 技术面试偏好与防守 SOP

16 条 LP 行为面试 (占 50% 权重)

每轮面试后半段必问 2-3 个 LP 问题，必须用 STAR 法则 (Situation-Task-Action-Result) 并带量化数据回答。

System Design ( AWS 最佳实践 )

追问重点：DynamoDB 扩展性、SQS/SNS 消息解耦、S3 吞吐与数据最终一致性。

Coding 严查逻辑无 Bug

LeetCode 中等题，要求 代码干净、变量命名规范、无边缘漏报错。
