2. 字节部门红黑榜动态矩阵

切换查看“推荐入坑”与“高危避坑”部门的技术栈与风气内幕：

Seed / 豆包 / AI Flow (AI & 大模型)
推荐理由：公司最高战略预算投入，拥有顶配万卡 GPU 算力集群。薪资溢价极高，HC 相对充裕，极度适合 AI / RAG / LLM / 模型推理与 Agent 方向。
基础架构 / Data (基础技术)
推荐理由：技术纯粹度高，背靠全局底层，沉淀深厚。远离前台业务线的直接生撕与指标 PUA，适合注重分布式、高并发、存储底层的工程师。
商业化 (Adtech / 穿山甲 / 广告系统)
推荐理由：字节最核心的“造血现金牛”利润中心，海量高并发与推荐算法场景。年终奖系数稳定，技术壁垒硬。
抖电 / 抖音电商 (Ecommerce)
避坑理由：高危重灾区！ 极高强度的 007 内卷，GMV 数字压迫感极强。业务策略高频变动，内耗极其严重，且拥有极高频次的 PIP 与劝退归流率。
TnS (Trust & Safety / 内容安全与合规)
避坑理由：高危避坑组！ 属于成本中心而非利润中心。24/7 紧急 On-call，面临极高的海外合规风险。内部数据口径政治拉扯极重，离职率高。
无 PMF 的赛马创新组 (孵化/硬件/游戏余脉)
避坑理由：内部“赛马”机制极其残酷，半年出不了成果就被整组解散。组员极易拿到 M- 绩效或被迫内部转岗。

数据驱动与 AB Test

一年两次考核（4月/10月）。保持 5% - 10% 的强制 PIP (I/M-) 淘汰率，非常看重跨部门协作满意度。
