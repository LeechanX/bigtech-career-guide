避坑理由：业务 ROI 难以闭环，容易因战略调整被整组缩减。

工作作息与“开水团”工程文化

工作作息 (1095 节奏)

普遍下班时间在 21:00 - 21:30。务实尚俭，追求极致工程效率。

苦干与 ROI 结果导向

极度注重逻辑推演与数据效果（“苦干+巧干”）。任何技术改造必须说清楚业务价值。

S / A / B / C 绩效评估

一年两次绩效。非常看重工程规范、线上零故障与 OKR 达成度。

美团技术面试偏好与防守 SOP

Java 高并发与中间件原理

必考：JVM 内存模型、Caffeine/Redis 多级缓存、RPC 异步调用与优雅降级。

实时调度算法与地理位置 (LBS)

核心考点：GeoHash / H3 空间索引、运筹优化算法、实时秒杀库存防超卖。

算法手撕严查边界

LeetCode 中等/困难题，要求 思路清晰、无编译 Error、边界异常捕捉完备。
