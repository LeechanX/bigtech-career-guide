2. 腾讯 BG 事业群红黑榜动态矩阵

切换查看“推荐入坑”与“高危避坑”事业群的技术栈与风气内幕：

WXG (微信事业群)
推荐理由：腾讯皇冠上的明珠，产品壁垒极深，现金流极其充沛。年终奖极其丰厚（动辄 10+ 个月），技术风气严谨纯粹，极难进入但性价比最高。
IEG 核心工作室 (天美 TiMi / 光子 LightSpeed)
推荐理由：腾讯绝对造血现金牛，游戏海外出口与长线运营实力强大。年终奖包极其可观，在大容量高并发、C++ 与游戏引擎方面技术积累深厚。
TEG (技术工程事业群)
推荐理由：腾讯的技术基建大脑（混元大模型、云计算底层、分布式存储）。不背前台业务线的业绩指标 PUA，技术风气纯粹，极其适合技术极客。
PCG (平台与内容事业群)
避坑理由：包含传统信息流、腾讯视频、微视余脉与 QQ 看点等业务。受外部短视频冲击严重，面临持续的业务收缩、架构重组与高频裁员。
CSIG 边缘政企 / 私有云定制化交付组
避坑理由：属于“乙方心态”的定制化项目。需要频繁出差驻场，技术复用率低且利润率薄，容易沦为降本增效的裁员首选。
IEG 边缘非核心 / 腰部小游戏组
避坑理由：腾讯内部“赛马”机制下被边缘化的团队。游戏上线后留存数据低即面临项目快速砍线、整组撤裁。

工作作息与通道答辩晋升文化

工作作息 (相对温和)

普遍下班时间在 20:30 - 21:00。相比字节和拼多多，整体 WLB 较好（WXG 与 IEG 核心版本上线期除外）。

瑞雪文化与 1.3/1.5/2.0 绩效

鼓励“瑞雪”职场正气。一年两次绩效考核（1.25、1.3、1.4、1.5 等），绩效直接绑定年终奖月份数。

专业通道答辩

职级晋升需通过“专业通道委员会”答辩。10 级升 11 级（原 3-2 升 3-3）存在明显卡槽门槛，非常看重系统架构设计能力。

腾讯技术面试偏好与防守 SOP

极度看重 C++ / Go 与底层机制

必考语言底层细节：C++ 虚函数表、指针内存管理、STL 源码、Go Goroutine 调度（GPM）与 GC 垃圾回收原理。

Linux 内核与网络编程

极度关注 TCP/IP 三次握手/四次挥手状态机（TIME_WAIT）、epoll IO 多路复用与网络抓包防守。

算法看重代码规范与边界

算法题难度不如字节 Hard，但极其注重 代码可读性、边界条件处理与无内存溢出风险。
